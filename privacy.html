Privacy Policy

Last updated: 29 October 2026

Aditya Studio ("the app") is a private tool operated by Aditya for managing the Aditya YouTube channel. This policy explains what data the app accesses and how it is handled.

Who can use the app

Only the channel owner signs in to the app. It does not accept sign-ins from the public.

Data the app accesses

With the owner's permission, granted through Google sign-in, the app uses the YouTube Data API and YouTube Analytics API to:

  • upload videos, thumbnails and captions to the owner's channel;
  • read and update the owner's video details, playlists and comments;
  • read the owner's channel analytics to improve future videos.

How data is stored

Sign-in tokens are stored privately on infrastructure controlled by the owner and are never published. Analytics data is used only to plan and improve the owner's own videos.

Sharing

The app does not sell, rent or share any user data with third parties, and does not use it for advertising.

Google API Services

The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions or via the Google security settings page. Stored tokens are deleted when access is revoked or on request.
